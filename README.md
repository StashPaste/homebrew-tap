# StashPaste Homebrew Tap

Install [StashPaste Light](https://stashpaste.com) on macOS 13 or later.

## Install

```sh
brew install --cask stashpaste/tap/light
```

## Update

```sh
brew update
brew upgrade --cask stashpaste/tap/light
```

## Uninstall

```sh
brew uninstall --cask stashpaste/tap/light
```

## Access

This repository is currently private and requires authorized GitHub access.

## Releases

The Light production release process updates `Casks/light.rb` with the release
version, its immutable versioned DMG URL and the matching SHA-256 checksum.
